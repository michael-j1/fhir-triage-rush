📖 Reference: Valid FHIR Patient

        
      

      

        A compliant FHIR R4 Patient record must contain all required resource attributes and standards-based formatting:
      

      
{
  "resourceType": "Patient",
  "id": "pat-8841",
  "active": true,
  "name": [
    { "family": "Miller", "given": ["Sarah"] }
  ],
  "gender": "female",
  "birthDate": "1989-04-12"
}

      
    
        
  • resourceType: Mandatory routing key for EHR endpoints.
    • 
        
  • active: Inactive records (false) are rejected from admission.
    • 
        
  • birthDate: Must strictly use ISO date format (YYYY-MM-DD).
